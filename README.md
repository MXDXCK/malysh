# Малыш — дневник мамы 👶

Простое приложение для мамы (и папы): кормления, прикорм, сон, рост и прививки малыша.
Работает на iPhone как обычное приложение с экрана «Домой», в том числе без интернета.

**Открыть:** https://OWNER.github.io/REPO/

## Что умеет

- **Кормление грудью** — таймер для левой и правой груди, пауза, подсказка, с какой стороны начать.
- **Бутылочка** — объём в мл, грудное молоко или смесь.
- **Прикорм** — продукт, граммы, реакция; список введённых продуктов (с отметкой, где была реакция).
- **Сон** — таймер «Уснул / Проснулся», ручное добавление, график сна за неделю.
- **Рост** — вес, рост, окружность головы, график и прибавки.
- **Прививки** — календарь по национальному календарю РФ с датами от дня рождения, отметки о сделанных, свои записи (визиты к врачам, грипп и т. п.).
- **Синхронизация** между телефонами мамы и папы — оба видят и редактируют одни и те же записи.
- **Обновления** — приложение само проверяет новую версию и обновляется одной кнопкой, данные сохраняются.
- Тёмная тема для ночных кормлений, резервная копия в файл.

## Как установить на iPhone

1. Откройте ссылку выше в **Safari**.
2. Нажмите «Поделиться» (квадрат со стрелкой) → **«На экран „Домой“»** → «Добавить».
3. Запускайте с иконки «Малыш». Записи вносите уже в установленном приложении — на iPhone данные Safari и установленного приложения хранятся раздельно.

## Синхронизация с телефоном папы

Нужен бесплатный проект Firebase (облако Google). Настраивается один раз:

1. Зайдите на https://console.firebase.google.com под своим Google-аккаунтом → **Create a project** (название любое, Google Analytics можно выключить).
2. **Build → Authentication → Get started → Sign-in method → Anonymous → Enable**.
3. **Build → Firestore Database → Create database** (регион — например, `eur3`; режим — production).
4. Во вкладке **Rules** Firestore вставьте содержимое файла [`firestore.rules`](firestore.rules) и нажмите **Publish**.
5. **Project settings (шестерёнка) → General → Your apps → значок `</>` (Web)** → зарегистрируйте приложение → скопируйте объект `firebaseConfig`.
6. Пришлите этот объект разработчику или вставьте его в [`firebase-config.js`](firebase-config.js) вместо `null`.

После этого в приложении: **Настройки → Создать семью** на одном телефоне, **код семьи** — ввести на втором.
Ключи из `firebaseConfig` не секретные: данные защищены правилами и 16-символьным кодом семьи, который знают только ваши телефоны.

## Как выходят обновления

1. Меняются файлы приложения, в `app.js` повышается `APP_VERSION`, в `sw.js` — имя кэша.
2. В `version.json` пишется та же версия и список «Что нового».
3. Изменения отправляются в этот репозиторий — GitHub Pages публикует их за 1–2 минуты.
4. В приложении появляется плашка «Доступна версия …» → «Обновить». Записи о малыше не затрагиваются.

## Устройство

Без сборки и зависимостей: `index.html`, `style.css`, `app.js` (интерфейс и данные), `sync.js` (Firebase),
`sw.js` (офлайн-режим), `manifest.webmanifest` и `icons/`. Данные хранятся в `localStorage` телефона,
при включённой синхронизации — ещё и в Firestore (`families/<код>/items/<id>`).
